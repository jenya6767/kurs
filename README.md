# Сравнение подходов к созданию графического интерфейса

Учебный проект для практической главы курсовой Жени. **Два настольных графических приложения на Python** с одинаковыми задачами: создание, отметка выполнения, удаление, счётчик, сохранение в JSON.

## Запуск

Python 3.10+; команды выполняются в корне репозитория.

**Tkinter (обычно входит в стандартную поставку Python):**
```bash
python -m apps.tk_app
```

**PySide6 (Qt Widgets):**
```bash
python -m pip install -r requirements-qt.txt
python -m apps.qt_app
```

**Тесты независимой от GUI логики:**
```bash
python -m unittest discover -s tests -v
```

## Сравнение

Tkinter: `ttk.Entry`, `Listbox`, callbacks `command=...`, компоновка `pack`. PySide6: `QLineEdit`, `QListWidget`, `QPushButton`, сигнал `clicked.connect(...)`, композиция `QVBoxLayout`/`QHBoxLayout`.

Общая логика: `taskcore/model.py` (`TaskBoard`). Графические интерфейсы не дублируют правила валидации и хранилище. Каждая реализация использует собственный JSON-файл: `data/tk_tasks.json` и `data/qt_tasks.json`.

Сравнение показывает конструкцию, зависимости и управление событиями. **Не измерялись время разработки, скорость интерфейса и пользовательская продуктивность.** Автоматические тесты проверяют общую модель, а не реальную работу двух окон; для ручной проверки предусмотрен `MANUAL_CHECKLIST.md`.
