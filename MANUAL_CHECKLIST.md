# Лист ручной проверки графических интерфейсов

Для Tkinter и PySide6 повторите одни и те же действия отдельно.

- [ ] Окно открывается, заголовок и поле ввода видны.
- [ ] Добавление `Составить макет` отображает задачу в списке.
- [ ] Пустое название вызывает сообщение об ошибке.
- [ ] При выборе задачи нажатие «Выполнена / вернуть» меняет её отметку.
- [ ] Повторное нажатие снимает отметку.
- [ ] Удаление выбранной задачи меняет список и счётчик.
- [ ] Повторный запуск сохраняет созданные задачи.
- [ ] При закрытии приложения нет ошибок в консоли.

Пока чек-лист не заполнен участником на конкретном компьютере, ручные проверки нельзя объявлять проведёнными. Скриншоты реального интерфейса следует получать в установленной среде.
